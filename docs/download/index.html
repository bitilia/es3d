Download

npm install @es3d/es3d

Pick an entry point

ImportWhat it isUse it for
@es3d/es3dThe whole library as ES modulesNode, a bundler, the converter in scripts
@es3d/es3d/browserEverything that runs in a browser, in one fileA page that parses, draws and converts files on the visitor's computer
@es3d/es3d/stageOnly the stage, in one smaller fileA page that shows a scene: stage API

A page without a build step loads either file from a CDN:

<canvas id="view"></canvas>
<script type="module">
  import { createStage } from 'https://cdn.jsdelivr.net/npm/@es3d/es3d@/browser/es3d-stage.min.js';
  const stage = await createStage(document.querySelector('#view'));
  stage.show(await (await fetch('scene.es3d')).text());
</script>

Converting a file the visitor picks, without uploading it:

import { importFiles, exportFormat } from 'https://cdn.jsdelivr.net/npm/@es3d/es3d@/browser/es3d.min.js';

const scene = await importFiles(input.files);       // SVG, OBJ (+ .mtl), STL, STEP, glTF, X3D, USDA, OpenSCAD
const { files } = exportFormat(scene.text, 'glb');  // or obj, stl, step, x3dv, usda, scad, js

Command line

npx @es3d/es3d validate scene.es3d
npx @es3d/es3d glb scene.es3d -o scene.glb
npx @es3d/es3d import drawing.svg -o drawing.es3d
npx @es3d/es3d --help
