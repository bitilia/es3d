Everything on this site is one free JavaScript project: the reference implementation, the renderer, ES3D Studio, the converter and the command-line tool. It is released under the Apache License 2.0, version .

1. The JavaScript library (npm)

npm install @es3d/es3d

The library runs in browsers and in Node.js 22 or newer. Parsing, validation, conversion and the exporters work everywhere. The renderer needs a browser with WebGPU or WebGL2.

import { compile, createRenderer, Camera } from '@es3d/es3d';

const result = compile(text);                     // parse, validate, build the scene
if (!result.ok) console.error(result.diagnostics.map((d) => d.format()).join('\n\n'));

const renderer = await createRenderer(canvas);    // WebGPU, else WebGL2
renderer.setScene(result.scene, (entry, lod) => result.cache.mesh(entry, lod));
const camera = new Camera().frame(result.scene.bounds);
renderer.render(camera, { width: canvas.clientWidth, height: canvas.clientHeight });

2. The command-line tool

The npm package includes the es3d command:

npx @es3d/es3d validate scene.es3d          # every error, with line, column and a hint
npx @es3d/es3d minify scene.es3d -o small.es3d
npx @es3d/es3d compact scene.es3d          # the short ES3D-C spelling of the same tree
npx @es3d/es3d glb scene.es3d --instancing -o scene.glb
npx @es3d/es3d obj scene.es3d -o scene.obj
npx @es3d/es3d stl scene.es3d -o scene.stl
npx @es3d/es3d step scene.es3d -o scene.step
npx @es3d/es3d import drawing.svg -o drawing.es3d   # also .obj, .stl, .step, .gltf, .glb
npx @es3d/es3d stats scene.es3d

Run npx @es3d/es3d --help for the full list.

3. The source code

git clone https://github.com/bitilia/es3d.git
cd es3d
npm install
npm run dev        # this site, with Studio, the converter and the demo sites: http://localhost:5173
npm test           # unit tests
npm run build      # static site in dist/ (any web server can host it)

Browse it on GitHub. The public pages live in docs/.

4. File types

ExtensionContentsMedia typeHow to recognize it
.es3dUTF-8 text: markup (the canonical spelling) or the compact syntax ES3D-Cmodel/vnd.es3dmarkup starts with <es3d after an optional XML declaration and comments; compact syntax starts with es3d after optional // comments
.es3d.gzThe same text, gzip-compressedthe type above, with content encoding gzipgzip magic bytes 1F 8B

A web server can send .es3d as text/plain; charset=utf-8. Compression is ordinary gzip, .es3d.gz. There is no special compressed extension.

5. What you need

  • To view and convert: a current browser. WebGL2 is enough. WebGPU is used when the browser has it. No plugin.
  • To build the project: Node.js 22 or newer, and npm.
  • To write ES3D: any text editor. Markup highlights reasonably well if the editor treats .es3d as XML. A namespace declaration is not required.
