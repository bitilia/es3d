I.

        
Ashby

        
Sixteen buildings, a mill, a keep and eight hundred trees, all in one ES3D file of ,  gzipped.

        
Scroll to walk in.

      

      

        
II.

        
The crossing

        
Wheat and barley in strips, and a stone bridge over the river. The road and the river are each a single line given a width.

      

      

        
III.

        
The gate

        
Sixty-six logs make the palisade. The file holds one log and a rule: repeat it every five degrees around the square.

      

      

        
IV.

        
The square

        
A well, three stalls and eight houses facing in. There are only three kinds of house. Each is defined once and placed again with a different roof.

      

      

        
V.

        
The church

        
A nave, a tower, and a four-sided cone for a spire. The path you are flying is written in the same file as the stones.

      

      

        
VI.

        
The keep

        
On the hill, a keep with four towers. The woods are seeded scatters, so every browser grows exactly the same trees.
