Making the Web 3D

A very brief introduction of the format from the founder. 15 October 2026.

For years, 3D file formats have prioritized precision, whether for 3D printing or high-quality renders. But the browser doesn't care about that level of precision. As long as you're within a pixel or so, precision isn't that important. Most websites with 3D models use simple designs, and no file format actually targeted that use case. Many sites literally used a scroll-through video instead.

I thought: this sounds a lot like what SVG does for 2D. What's stopping us from making it 3D? Turns out: nothing.

So I sat down and built it.

ES3D (Extensible Scalable 3D) is a file format for 3D scenes. It does for a scene what SVG does for a drawing. The file describes the objects: a rounded box here, an outline extruded into a solid there, two thousand trees on a hill. The viewer builds the triangles at the detail the screen actually needs. A forest fits in under a kilobyte, and a text editor is enough to write it.

The main question is: Does it actually work? I believe it does, and here are some benchmarks to prove it.

Not only that. The showcase sites are interactive 3D designs made with it. I took the best of SVG and applied it to 3D.
